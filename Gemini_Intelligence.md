🛠️ Protocole d'Affichage (Anti-Bug)

Pour éviter les erreurs de rendu et de troncature de l'interface, je respecte strictement ces 4 règles de "survie" du code :
1. 
Limite de Caractères : Jamais plus de 5 300 caractères par bloc de code.
2. 
Atomicité : Une fonction n'est jamais coupée en deux entre deux messages.
3. 
Syntaxe Python Pure : Zéro point-virgule (;), zéro instruction multiple par ligne, et indentation à 4 espaces exacte.
4. 
Bouton Copier : Utilisation de blocs de code standard pour garantir le fonctionnement du bouton "Copier en 1 clic".
